=Notes= Styling text
font = value
The current text style being used when drawing text. 
This string uses the same syntax as the CSS font 
property. The default font is 10px sans-serif.

textAlign = value
Text alignment setting. Possible values: start, end, 
left, right or center. The default value is start.

textBaseline = value
Baseline alignment setting. Possible values: top, 
hanging, middle, alphabetic, ideographic, bottom. 
The default value is alphabetic.

direction = value
Directionality. Possible values: ltr, rtl, inherit. 
The default value is inherit.

=Note 1= 
フォントサイズを大きくするには？  
ctx.font = "48px serif"; の数字を増やすだけで大きくなります。

=Note 2=  
小数1桁（xx.x）にするには？ 
toFixed(1) で小数第1位までに制限されます。
例えば 16.123 → "16.1" になります。

=Note 3=  
textの色を指定するには？
// 赤色で fillText を描画
ctx.fillStyle = "red";
ctx.fillText("Hello world", 10, 50);

// 青色で strokeText を描画
ctx.strokeStyle = "blue";
ctx.strokeText("Hello world", 10, 50);
